## Explicit Survey Exclusions / Not-Taken Patterns (§0.1 — No Silent Skips)

| Source | Pattern / Module Not Taken | Exact Reason |
|---|---|---|
| **Hermes Agent** | **Camofox anti-detection browser** | Strictly forbidden by §0 (fingerprint spoofing / anti-bot evasion policy). |
| **Hermes Agent** | Modal / Daytona / Vercel Sandbox / Singularity cloud VM backends & `cli.py` interactive PTY daemon | Uses external paid/cloud sandbox infra or interactive SSH/PTY outside our self-hosted FastAPI + Docker/Windows VPS stack; replaced with workspace-scoped sandbox & git worktrees. |
| **Hermes Agent** | Signal / Feishu / Lark / Discord / Slack live bot SDK daemons & Neutts C++ audio binary | Need external SDKs/platform app credentials owner does not currently configure; unified WhatsApp/Telegram/Email/Voice gateway routes cover owner channels cleanly. |
| **DeepSeek Harness** | TypeScript worker monorepo runtime (`packages/ptc-runtime`, `apps/cli`, `apps/desktop-host`, `win32-process` native addon) | Incompatible stack (our backend is Python FastAPI + Next.js, TypeScript runtime dropped per §0.1 rule B). Design/UI patterns extracted cleanly. |
| **Agent Flow Harness** | Desktop Electron updater & local `.exe` installer (`afh/tui`, `desktop/`) | Windows/desktop binary wrapper out of scope for Phase 8 web platform (planned only in native wrapper phases). |
| **OpenMausBot** | Cloudflare Workers remote relay (`cloudflare/`, `relay/`), macOS/Electron Companion (`companion/`, `electron/`) | Requires external Cloudflare/Apple signing credentials & separate TypeScript server runtime; adapted local vs cloud operator UX & replay scrubber cleanly into Python/Next.js. |
| **Manus** | Multi-tenant cloud VM hypervisor billing & closed backend orchestration | Proprietary closed infrastructure; adapted single-tenant persistent sandbox directories, projects, wide research, and deliverable previews cleanly. |
| **Instinct Snapshot** | Unauthenticated root `agent-exec-server`, plaintext `auth.json` keys, world-readable S3 creds wrappers (`REPORT-3-final.md` C1–C6) | Intentionally rejected critical security flaws; enforced JWT/2FA auth, non-privileged workspace isolation, Fernet encryption, Blind-Fill scrubbing, and opt-in training. |
